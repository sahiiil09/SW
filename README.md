# Shadow World — Attendance & Management System

A modern web-based Attendance & Management System built with a premium Frost Glassmorphism UI, responsive layouts, and lightweight client-side architecture.

## ✨ Features

- Modern Frost Glassmorphism design
- Smooth Light/Dark mode switching
- Admin & User dashboards
- One-click attendance system
- Registration approval/rejection workflow
- Attendance history & activity logs
- Trash system for deleted members
- Real-time styled activity feed
- LocalStorage-based persistent data
- Fully responsive & portable

## 🎯 Project Goal

Shadow World is designed to deliver a lightweight, visually premium, and easy-to-deploy attendance management experience with modern UI aesthetics and seamless usability.
